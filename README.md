# Typer
Program for typing command scripts in roblox in C (NOT C++!!!! THEY ARE NOT THE SAME)

USAGE\
-- compilation:\
gcc main.c -o main -luser32 -lpthread\
-- running:\
ESC to terminate program\
RSHIFT to execute program in cmd.txt\
keys can be activated globally in any program

ocassionally, windows defender will not allow the compiled program to run\
because it is intercepting with keyboard input. To deal with this, run the program\
as administrator or disable windows defender software.
